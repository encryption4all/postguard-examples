# PostGuard Examples

Example applications demonstrating [PostGuard](https://postguard.eu) encryption and delivery via Cryptify.

## Examples

| Directory | Stack | Description |
|---|---|---|
| [`pg-dotnet`](pg-dotnet/) | .NET 10 console app | Encrypt files and upload/deliver via the [postguard-dotnet](https://github.com/encryption4all/postguard-dotnet) SDK |
| [`pg-sveltekit`](pg-sveltekit/) | SvelteKit web app | Browser-based encrypt & send UI using [@e4a/pg-js](https://www.npmjs.com/package/@e4a/pg-js) |

Each example has its own README with setup instructions.
